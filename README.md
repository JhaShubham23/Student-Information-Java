# Student Information System

A simple Java console application that collects student details (Name, Age, Roll Number) and marks for three subjects to calculate the total and average percentage.

## Features
- Accepts student personal information via terminal input.
- Takes percentage marks for 3 distinct subjects.
- Computes and displays the **Total Marks** and **Average Percentage**.

## How to Run
1. Make sure you have **Java Development Kit (JDK)** installed.
2. Compile the program:
   ```bash
   javac Main.java
   ```
3. Run the program:
   ```bash
   java StudentInformation
   ```
